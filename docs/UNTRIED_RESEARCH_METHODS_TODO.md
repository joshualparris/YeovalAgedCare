**Scope:** discover *genuine* architectural site plans, approved drawings, complete parcel boundaries, exterior footprint dimensions, elevations, historic construction phases and, where appropriately released, public-safe internal layouts.

> **Important honesty note:** This is a **backlog of methods not yet executed to completion**, not evidence that they have been tried and failed or that the requested plans exist. A cited/source-linked website is **not the same as a completed parcel lookup, map inspection, DA search, records request, scan or measurement**. Broad web searches, public annual reports and brochures were investigated previously; those completed tasks are **not** rebranded as untried below. It is impossible to list literally every conceivable technique; this is a comprehensive practical inventory by value and feasibility.

## Definition of done for each genuine discovery

1. The source was **opened/downloaded/queried**, not merely discovered via search snippets.
2. Correct building and correct historic date were confirmed.
3. Documentary identifier, dimensions, projection/scale or source photo coordinates were captured with uncertainty.
4. The result distinguishes **approved/proposed** vs **completed/as-built**.
5. File has permitted reuse; otherwise publish description, metadata and link **only**.
6. Corresponding entry in [architecture evidence](YEOVAL_ARCHITECTURE_EVIDENCE.md) and [geometry status](../data/yeoval_geometry_status.json) updated.
7. Any changed drawing or measurements have a reproducible method and live GitHub verification.
